# Claude 日常启用

> 整理日期：2026-11-05
> 适用范围：本机已有 Claude 配置

## 启动与检查

### 启动顺序

1. **打开代理**：启动 Clash Verge。
2. **确认模式**：使用 `Rule` 规则模式，TUN 开启，系统代理关闭。
3. **确认节点**：`ACCOUNT-US` 使用自己选定的节点。
4. **程序检查**：打开桌面 `Claude 环境卫士` 做体检；想查得更深，再跑一键总检。
5. **网页检查**：程序检查通过后，在实际使用的专用浏览器核对出口、DNS、WebRTC、IPv6、语言和时区。
6. **启动应用**：由自己选择所需桌面图标。

### 检查结果处理

| 检查结果 | 接下来做什么 |
|---|---|
| `PASS` | 查看其余检查项 |
| `WARN` | 查看具体原因，必须处理防护相关警告 |
| `FAIL` | 停止启动，交给 AI 排查 |
| `MANUAL` | 完成对应的真实网页人工检查 |

**Anthropic 网段阻断**：总检会核对 `160.79.104.0/23`、`153.61.224.0/22` 的系统出站规则；规则缺失或配置变化时显示 `FAIL`，按[网段直连阻断说明](Anthropic网段直连阻断.md)处理。

### 后台出口巡检

- **是什么**：计划任务「Claude后台出口巡检」每 5 分钟在后台跑一次 [后台出口巡检.ps1](../工具/后台出口巡检.ps1)，约 10 秒、不弹黑窗口；查三个专用端口经 `claude.ai/cdn-cgi/trace` 看到的国家是不是 `US`、Clash 是不是直连模式或全局没选 `ACCOUNT-US`、防火墙总开关和两条网段阻断；另外每天一次跑 [检查Claude官方域名.ps1](../Clash/检查Claude官方域名.ps1)，官方清单出现没归类的新域名也弹窗（把弹窗内容发给 Claude 判断要不要加规则）。
- **出问题时**：失败项和上次不一样才弹一次窗；只提醒，不改防火墙、Clash，也不关 Claude。看到弹窗先别用 Claude，处理好后打开环境卫士复查。
- **不弹窗的情况**：连不上 Claude（Clash 没开或线路慢）、读不到 Clash 只记日志；出口 IP 变了只记一笔。
- **边界**：最多有一个周期（5 分钟）的暴露窗口，真正挡直连的仍是 WFP 规则和防火墙；不访问第三方测 IP 站。
- **日志**：`%LOCALAPPDATA%\ClaudeNetworkGuard\后台出口巡检\`（`巡检日志.log` 留最近 3000 行，`最近结果.json` 是上一轮）。

| 要做什么 | 命令（PowerShell 7，在 `工具` 目录下） |
|---|---|
| 看任务状态和最近一次结果 | `.\后台出口巡检.ps1 -Status` |
| 手动巡检一次 | `.\后台出口巡检.ps1` |
| 验证弹窗（不改任何设置） | `.\后台出口巡检.ps1 -SimulateLoc CN` |
| 注册 / 删除计划任务 | `.\后台出口巡检.ps1 -Install` / `-Uninstall`；本机普通权限建不了计划任务，普通窗口跑会打印一行提权命令，粘贴后点一次 UAC |

### 验收边界

- **节点变更**：更换节点后重新建立连接并复验。
- **入口隔离**：一个浏览器的检查结果不能替另一个浏览器放行。
- **历史结果**：以前通过不代表今天正常。

## 桌面入口与维护

| 桌面图标 | 作用 |
|---|---|
| `Claude-环境一键总检` | 检查配置，可能打开专用 Chrome 检测页；环境卫士的「深度总检」调同一个脚本（`-ResultPath` 写 JSON） |
| `Claude-英文浏览器` | 检查通过后打开 Claude Desktop；环境卫士 Desktop 卡片的「检查后启动 Desktop（英文）」调同一个脚本 |
| `Claude-三端更新` | 退出 Claude 后双击：查三端版本，有新版才下载安装并同步防护，一次 UAC |
| `Claude-系统架构` | 打开[入口页](架构讲解.html)：架构、防护、规则、出问题去哪改都在这一页 |
| 对应账号的专用 Chrome | 使用该账号独立的浏览器数据 |

- **维护默认**：AI 更新或检查时不启动 Claude Desktop 或 Claude Code。
- **更新**：退出全部 Claude 后双击桌面「Claude-三端更新」，没新版只查验、有新版自动下载安装并同步防护（插件落后也自动装，只要求先退出 VS Code；等得久看屏幕提示，详见 [更新维护说明](../Desktop防护/更新维护说明.md#失败与同版本)），一次 UAC。更新完在本项目说「更新完了」，AI 读记录写日志。细则见 [claude-maintenance](../../../../.agents/skills/claude-maintenance/SKILL.md)。
